# Ocheche Fredrick — Developer Portfolio (`ocheche.dev`)

Welcome to the source repository for my personal developer portfolio and engineering showcase.

A modern, high-performance portfolio site built with semantic HTML5, modern CSS3, and vanilla JavaScript, featuring an interactive dark purple neon aesthetic, dynamic showcase tabs, and defense-in-depth full-stack project spotlights.

---

## 🚀 Live Features

- **Split Hero Section**: Introducing my background as a Full-Stack Developer & Cybersecurity Practitioner, featuring a floating photo with ambient glow effects.
- **Interactive Showcase Tabs**:
  - **What I Do**: Expandable role cards (*Web Developer*, *Full-Stack Engineer*, *Cybersecurity Practitioner*, *Backend Developer*, *Database Designer*).
  - **Ongoing Projects**: Featured case studies including **Maison Royale Hotel** (Go & SQLite booking platform with CSRF protection, secure sessions, and rate limiting).
  - **Tech Stack**: Clean grid highlighting core tooling across Go, Python, JavaScript, HTML5, CSS3, SQLite, Linux, and GitHub.
- **Connect & Contact**: Interactive direct cards for GitHub, LinkedIn, WhatsApp, and X/Twitter ([@FredyRemedy](https://x.com/FredyRemedy)), plus direct email integration.
- **Responsive Architecture**: Fully optimized for mobile, tablet, and widescreen displays.

---

## 🛠️ Built With

- **HTML5**: Semantic tags, accessible navigation, and SEO meta tags.
- **CSS3**: CSS custom properties (variables), glassmorphism, responsive grid/flexbox, keyframe animations (`@keyframes floatGlow`).
- **JavaScript (Vanilla)**: Lightweight DOM event handling for tab switching and mobile navigation with zero heavy dependencies.

## 💻 Local Development

To run and preview the portfolio locally:

```bash
# Clone the repository (once pushed)
git clone https://github.com/smilinqremedy/<your-repo-name>.git

# Navigate into the project folder
cd my-portoflio

# Start a local preview server
python3 -m http.server 3000
```

Then open your browser and navigate to `http://localhost:3000`.
